UI/UX lab

I treat design as a way of thinking, not decoration. This is the process I follow on the screens I build.

  1. Listen firstWho is using this, and what state are they in? A commuter at night needs something different from a student on a laptop.
  2. Sketch before codePaper wireframes, then user flows. Cheap to change, so I change a lot.
  3. Build the smallest real versionClean components, readable type, visible focus states, mobile first.
  4. Test with real peopleWatch where they hesitate, then fix that.
